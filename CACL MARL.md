**Selective Intention Communication in Cooperative Multi-Agent Reinforcement Learning**  
Team Members: Genesis Hang, Robel Tadele, Leo Ding

**Problem and motivation.** In cooperative multi-agent reinforcement learning (MARL), agents coordinate better when they know what their teammates intend to do. Without that knowledge, they duplicate effort, block each other's paths, and waste time. Existing communication methods often have agents share intentions at every step, which adds overhead and is often unnecessary, since most steps involve no conflict at all. In real systems such as warehouse robots or autonomous vehicles, communication has bandwidth, latency, and energy costs. We ask: can agents learn when sharing an intention actually improves coordination, and stay silent otherwise?

**Proposed approach.** We build on SeqComm (Ding et al., "Multi-Agent Coordination via Multi-Level Communication," NeurIPS 2024), which coordinates agents through intention-based negotiation and sequential action communication. We study this in Overcooked-AI (Carroll et al., NeurIPS 2019), where two agents must coordinate ingredient collection, cooking, and delivery under time pressure. Inspired by SeqComm's sequential decision-making framework, we implement a simplified baseline in which one agent communicates its intended task before its teammate selects an action. We then extend this baseline with three components:

1. Private intentions with sequential sharing: each agent maintains a private intended task (e.g., "fetch onion," "plate soup") that its teammate cannot observe. In our simplified SeqComm baseline, one agent communicates its planned task before its teammate selects an action, so the teammate can avoid conflicts.  
2. Conflict-aware heuristic gate: before each decision, an agent decides whether to send its intention or stay silent, using a rule based on observable teammate positions, the agent’s own intended task, previously communicated intentions, and potential movement interference. It speaks only when its plan is likely to collide with or duplicate its teammate's.  
3. Learned communication gate: we substitute the heuristic rule with a gating policy trained via approximate Q-learning, incorporating features including distance to teammates, shared task objectives, and projected trajectory intersections. The objective function penalizes each transmission with a fixed message cost while rewarding multi-step coordination improvements (preventing task duplication and physical obstruction), enabling agents to broadcast only when the anticipated benefit exceeds the communication penalty.

Agents navigate with A\* path planning and select tasks with a fixed policy (scripted, or trained with PPO), held constant across all conditions so that differences reflect communication alone. We compare no communication, full sequential communication (every step), heuristic selective communication, and learned selective communication, and vary the communication cost to map the trade-off between performance and message volume. As a stretch goal, we extend Overcooked to a 2v2 setting in which opponents can overhear broadcast intentions, testing whether agents learn to communicate less when messages leak information to the other team. The adversarial team follows a deterministic policy engineered to leverage intercepted communication (for instance, preemptively intercepting declared targets), allowing us to evaluate information leakage risks alongside overall task success.

**Datasets and evaluation.** We use the Overcooked-AI environment across several kitchen layouts with different coordination demands, including narrow corridors and shared workstations (e.g., Cramped Room, Coordination Ring, Forced Coordination). These layouts range from loosely coupled tasks to ones where agents constantly interfere, and they are fast to train on CPU. We measure team performance (average team reward and completed orders per episode), coordination quality (blocked movements and duplicated task assignments), communication efficiency (messages sent per episode and communication-adjusted reward), and sensitivity to communication cost (performance as message cost increases). We report the interquartile mean with bootstrap 95% confidence intervals over multiple random seeds per layout.
